# MinerU 4.x GPU 部署依赖 —— 独立环境，勿与 py-parse/requirements.txt 混装
#
# py-parse 只通过 HTTP 调 MinerU（httpx），本身不依赖 torch/vLLM。这份清单
# 供 MinerU 服务单独建环境用。
#
# 安装分两步（torch 必须走 PyTorch 官方 CUDA index，从 PyPI 装会得到 CPU 版，
# 导致 mineru 静默回退 CPU、GPU 不生效）：
#
#   1) 先装 CUDA 版 torch —— 按 GPU driver 选 CUDA 版本：
#        # driver >= 560（可跑 CUDA 12.6）：
#        pip install torch --index-url https://download.pytorch.org/whl/cu126
#        # driver 535 这类（CUDA 12.2，跑不了 cu126）：
#        pip install torch --index-url https://download.pytorch.org/whl/cu118
#
#   2) 再装 MinerU full（含 vLLM，Linux 高吞吐 VLM 引擎）：
#        pip install -r requirements-mineru.txt
#
# 验证 GPU 生效：
#   python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
